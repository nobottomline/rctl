 1. 🎤 Микрофон — прямой аналог камеры: тот же Darwin-триггер + захват в активном приложении
   (kTCCServiceMicrophone). «Запиши N секунд» или живой аудио-стрим из любого приложения. Логичнейший
   следующий шаг.
   2. 🖥 Remote shell (/v1/exec) — выполнение произвольных shell-команд (демон — root). Реализуется за
   полчаса, а по мощности для контроля/автоматизации — огромно. Считаю это самым выгодным одиночным
   добавлением.
   3. 🖼 Фотогалерея — листать/скачивать камера-ролл (Photos DB, демон-root) + сохранять наши снимки в
   Фото.
 
   📡 Сбор данных (демон root читает что угодно):
   - 👤 Контакты / SMS / история звонков — читать AddressBook, Messages, call log (БД по известным путям).
   - 🔔 Уведомления — перехват входящих (хук доставки).
   - 📍 Геолокация / трекинг (CLLocationManager).
   - ⌨️ Перехват ввода / история буфера — логировать набранный текст и изменения clipboard.
 
   🎬 Медиа / стрим:
   - 📹 Живой стрим камеры (не только снимки) — как экран.
   - 🔊 Стрим аудио устройства (что играет) — сложнее, нужен системный аудио-тап.
   - 💾 Запись экрана в файл (live-стрим уже есть).
 
   🎛 Управление / автоматизация:
   - 🔁 Менеджер приложений — список/убийство/удаление/запуск.
   - 📞 Инициировать звонок / отправить SMS удалённо (CoreTelephony).
   - ⏰ Движок автоматизаций по триггеру/расписанию (есть /v1/script + запись жестов — расширить).
 
   🥷 Скрытность:
   - 👻 Скрытый режим — спрятать след rctl, анти-детект; авто-reconnect/heartbeat.
