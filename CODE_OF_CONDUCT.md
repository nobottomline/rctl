# Code of Conduct

## Our Commitment

We are committed to making participation in rctl respectful and harassment-free for everyone, regardless of background, identity, experience, or level of technical expertise.

## Expected Behavior

Examples of behavior that supports a healthy project include:

- communicating clearly and respectfully;
- giving and accepting constructive technical feedback;
- focusing disagreements on evidence, behavior, and project outcomes;
- respecting privacy, security boundaries, and responsible disclosure;
- taking responsibility for mistakes and helping repair their impact.

Examples of unacceptable behavior include:

- harassment, threats, discrimination, or personal attacks;
- sexualized language or unwanted attention;
- publishing another person's private information without permission;
- deliberately disrupting project discussions or development;
- using project infrastructure to facilitate unauthorized access to devices or data.

## Scope

This code applies in repository discussions, issues, pull requests, reviews, and other public spaces where someone is representing the project.

## Reporting

Report conduct concerns privately to the repository owner using a private contact method listed on the [maintainer's GitHub profile](https://github.com/nobottomline). Do not publish sensitive incident details in a public issue. Conduct reports will be reviewed promptly, kept confidential as far as reasonably possible, and handled without retaliation.

Security vulnerabilities should be reported through GitHub's private vulnerability reporting for this repository rather than through the conduct process.

## Enforcement

Project maintainers may edit or remove contributions and may issue a correction, warning, temporary restriction, or permanent ban when behavior violates this code. Enforcement decisions will consider the severity, intent, repetition, and impact of the behavior.

Maintainers who do not follow or enforce this code consistently may be removed from project responsibilities.
